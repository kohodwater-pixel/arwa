# Social media template system

## Formats

| Format | Size (px) | Safe area |
|---|---|---|
| Feed portrait | 1080 × 1350 | Keep key content in the central 1080 × 1080 (grid crop) |
| Square | 1080 × 1080 | 60 px margin |
| Story / Reel cover | 1080 × 1920 | Keep clear 250 px top and 340 px bottom |
| Landscape (LinkedIn / X) | 1200 × 627 | 50 px margin |
| Profile picture | 1080 × 1080 | Design for a circular crop |
| Highlight cover | 1080 × 1920 | Icon inside central circle |

Verify sizes with each platform before production; they change.

## Post types to template

1. **Announcement** — headline, date or detail, logo
2. **Quote / testimonial** — quote, name, role
3. **Product or service** — image, name, one benefit, CTA
4. **Tip / educational** — title, 1–3 points
5. **Offer** — offer, terms, validity, CTA
6. **Carousel** — cover, content slides, closing CTA slide
7. **Occasion greeting** — national and religious occasions relevant to the client's market

## System rules

- One grid and one margin across all types
- Fixed logo position and size
- Type scale: headline, subhead, body, caption — Arabic and Latin
- Colour rotation so the grid looks varied but unmistakably one brand
- Arabic templates are RTL, not flipped Latin ones
- Text short enough to read in two seconds on a phone

## Content calendar columns

Date · Platform · Post type · Objective · Copy AR · Copy EN · Visual brief · Hashtags · Status · Link to file
