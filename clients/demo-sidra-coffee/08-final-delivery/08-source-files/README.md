# Source files · الملفات المصدرية

Editable sources, each in its own self-contained folder: the HTML file plus an `assets/` folder holding every font, image and style sheet it uses. Open the HTML in a browser to view it; edit it in any code editor; export to PDF with the browser's print function or the agency's export script.

| Folder | What it is the source of |
|---|---|
| `brand-strategy/` | Brand strategy summary (PDF in `00-brand-strategy/`; the Markdown text is there too) |
| `brand-guidelines/` | Brand guidelines PDF |
| `company-profile/` | Company profile PDF |
| `instagram-post/` | Instagram post PNG |
| `logo-animation/` | Logo animation MP4 (the HTML plays the animation; it needs no other files) |

Sources kept elsewhere in this package:
- **Logo:** the SVG files in `01-logo/svg/` are the master artwork.
- **Presentation:** the `.pptx` in `06-presentations/` is itself the editable file.
- **Landing page:** `04-digital-social/landing-page/` is the working HTML and CSS.

Not included: the agency's internal build scripts and working previews, and the Figma test file (colour variables only, out of date).
