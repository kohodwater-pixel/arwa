# Logo — PROVISIONAL trace (v02)

**Status: provisional.** We rebuilt the logo from the client's identity board because no vector file was supplied. The only source is `_originals/ahmed-emaar-holding_identity-board_reference.webp`, where the mark is about 113 px tall. This is not master artwork. Replace it as soon as the client sends the original file.

## Files
- `ahmed-emaar-holding_logo_provisional-trace_ar-en_v02.svg` / `.pdf`: gold on a transparent background.
- `ahmed-emaar-holding_logo_provisional-trace-on-navy_ar-en_v02.svg` / `.pdf`: gold on navy #102232.

Each file contains three welded compound outlines (mark, Arabic name, English name). There is no live text, no stroke and no clipping, and each outline uses gold #D4A95F.

## How faithful it is
- **Mark:**
  - It was redrawn geometrically. It overlaps the gold pixels of the reference cover logo by 95% (IoU 0.95), measured at 8× zoom.
  - The comparison sheet is `_work/ahmed-emaar-holding_logo_provisional-trace_comparison_v02.png`.
- **Lettering:** this is a typeface match, not a trace.
  - Arabic is Cairo Bold (700). The reference is slightly wider, and its ح is more open.
  - English is Inter SemiBold (600) with 0.24 em tracking. The reference capitals are slightly wider.
  - Both fonts use the SIL Open Font License.

## Three mark details the board cannot resolve (ask the client)
1. **Swoosh tip and the middle bar.** The right end of the swoosh stops about 1.5 board px short of the middle bar. At this resolution the board does not show whether it touches the bar or stops short. The trace stops short.
2. **Cut line under the swoosh.** The board shows a thin dark sliver under the swoosh, next to the left bar. It may be a cut that separates the swoosh from the bar, or it may only be a bevel shadow. The trace ignores it, so there is no cut.
3. **Flag at the top of the tall bar.** The tall bar's roof wedge overhangs to the left over the gap, with a flat underside at about 96 board px. The size of the overhang and whether its tip touches the middle bar are uncertain. The trace keeps a small gap.

## Fabrication changes used on the shop sign (v03/v04, letters on the wall)
These apply to the sign's cut file only. They do not change the logo trace files.
1. **Swoosh tip cut off** where it would be thinner than about 1.5 cm at sign size. This was cut at 151.6 board px, so the mark becomes 41.9 cm wide instead of 44.7 at 44.4 cm high.
2. **English line set in Inter ExtraBold (800) instead of SemiBold (600)**, with tracking 0.26 em, so every stroke reaches about 1.5 cm when built as raised letters.
