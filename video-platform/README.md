# Mashhad Studio — منصة إنتاج الفيديو السينمائي من النص

> «Mashhad Studio» اسم عمل مؤقت (يتغيّر من `APP_NAME`)، وليس اسمًا مفحوصًا تجاريًا.

منصة ويب تحوّل وصفًا نصيًا بسيطًا إلى تصور إخراجي، ثم مخطط مشاهد قابل للتعديل، ثم ترسل كل مشهد إلى محرك توليد الفيديو المتصل، وتجمع المقاطع مع الصوت في فيلم واحد.

## التشغيل

```bash
cd video-platform
npm install
cp .env.example .env        # أضف مفاتيح المزودين إن وُجدت
npm run build               # يبني الواجهة إلى dist/
npm start                   # http://localhost:4000
```

- المتطلبات: Node.js 22.13 أو أحدث، و`ffmpeg`/`ffprobe` في المسار.
- أول حساب يُسجَّل يصبح مديرًا (أو الحساب المطابق لـ`ADMIN_EMAIL`).
- للتطوير: `npm run dev` للخادم و`npm run dev:web` للواجهة (Vite على 5173 مع تحويل `/api`).
- الاختبارات: `npm test`، واختبار المسار الكامل على خادم يعمل: `node test/flow.mjs http://localhost:4000`.

## ما الذي يعمل فعلًا، وما الذي لم يُختبر

| الجزء | الحالة |
|---|---|
| الحسابات، الصلاحيات، المشاريع، المخطط، قائمة المهام، التخزين، التجميع بـffmpeg، المشاركة، لوحة المدير | يعمل ومُختبر آليًا (API + متصفح) |
| محرك الإخراج (القواعد) | يعمل ومُختبر |
| **الوضع التجريبي** | يعمل. **لا يولّد فيديو بالذكاء الاصطناعي**: يرسم بطاقات بديلة موسومة «DEMO» لتجربة المسار فقط |
| محوّلات Runway و Google Veo و Luma | مكتوبة من SDK/أمثلة المزود الرسمية ومُختبرة على خادم محلي يحاكي أشكال الردود. **لم تُجرَّب مع الخدمة الحية** لعدم توفر مفاتيح |
| **المحرك الخاص** (`engine/`: خدمة مستقلة + عامل GPU لنماذج مفتوحة المصدر) | يعمل كاملًا بعامل تجريبي ومُختبر. **لم يُشغَّل أي نموذج حقيقي** (لا GPU في بيئة البناء). الدراسة في `docs/self-hosted-engine-study.md` |
| محوّل Kling | **تجريبي وغير موثَّق**: تعذّر فتح توثيق المزود وقت الكتابة. يُراجع قبل الاعتماد عليه |
| محوّل الصوت ElevenLabs | مكتوب من SDK الرسمي، لم يُجرَّب مع الخدمة الحية |
| المخرج الذكي (Claude) | مكتوب بـSDK الرسمي، لم يُجرَّب لعدم توفر مفتاح. عند أي فشل يعود النظام لمحرك القواعد |
| استعادة كلمة المرور | لا توجد خدمة بريد: الرابط يصدره المدير من لوحة التحكم (أو يظهر في سجل العمليات) |

بعد إضافة مفتاح من «لوحة المدير ← مزودو الخدمة» استخدم زر **اختبار الاتصال** (طلب موثَّق حقيقي)، ثم ولّد مشروعًا قصيرًا للتحقق من المحوّل.

### إضافة مزود فيديو جديد

أنشئ `server/providers/<name>.js` بنفس شكل المحوّلات الموجودة، ثم أضفه إلى القائمة في `server/providers/index.js`. لا شيء آخر في المنصة يشير إلى مزود باسمه.

```js
export default {
  id, label, demo: false, verified: 'sdk', docsUrl,
  credentialFields: [{ key: 'apiKey', label, env: 'X_API_KEY', secret: true, required: true }],
  qualities: () => [{ id: 'standard', label, resolution, aspects: { '16:9': '<قيمة المزود>' },
                      clip: { min, max, values? }, maxPromptChars, negativePrompt, imageToVideo, nativeAudio }],
  maxConcurrent, minPollMs,
  async submit({ prompt, negativePrompt, duration, aspect, quality, image }, creds) → { jobId, clipDuration },
  async poll(jobId, creds) → { status: 'pending'|'running'|'succeeded'|'failed', progress?, videoUrl?, downloadHeaders?, error?, retryable? },
  cancel?(jobId, creds), test?(creds),
};
```

الواجهة تعرض الجودة والأبعاد والمدد من `qualities()` مباشرة، فلا يظهر خيار لا يدعمه المحرك.

## الأمان

- مفاتيح API على الخادم فقط (متغيرات البيئة أو قاعدة البيانات مشفّرة)؛ المتصفح يرى آخر 4 خانات فقط.
- الملفات المرفوعة تُفحص بتوقيع الملف وبـffprobe، مع حدود للحجم والنوع.
- الفيديوهات خاصة بصاحبها؛ المشاركة برمز عشوائي يمكن إيقافه.
- حدود لكل مستخدم: ثواني التوليد اليومية، المشاريع الجارية، التخزين.

## قبل الإنتاج

- اضبط `APP_SECRET` و`COOKIE_SECURE=true` و`PUBLIC_BASE_URL` وشغّل خلف HTTPS.
- خادم واحد: SQLite والقرص المحلي كافيان. لعدة خوادم: استبدل `storage.js` بتخزين كائنات و`queue.js` بقائمة مشتركة (الواجهتان صغيرتان عمدًا).
- اربط خدمة بريد لاستعادة كلمة المرور.
- حدود المزودين (المدد، الأبعاد، طول البرومبت) مدوّنة في رأس كل محوّل مع مصدرها وما هو افتراض؛ راجعها مع توثيق المزود عند الربط.
