# Brand checklist

Use for identity systems and brand guidelines. Every box must be ticked or marked N/A with a reason.

## Strategy
- [ ] Approved strategy exists and is reflected in `brand-context.md`
- [ ] Each identity element can be traced to a strategic point
- [ ] The identity is distinct from every competitor in the audit

## Logo
- [ ] Primary, secondary and icon versions exist
- [ ] Arabic, Latin and bilingual lockups are balanced in weight and size
- [ ] Works in one colour, in black, and reversed
- [ ] Legible at 16 px and 10 mm
- [ ] Clear space and minimum size defined
- [ ] Vector artwork is clean: no stray points, strokes expanded, text outlined
- [ ] Preliminary conflict check done; client told a formal trademark search is needed

## Colour
- [ ] Every colour has HEX, RGB, CMYK and Pantone
- [ ] Text and background pairs meet WCAG AA
- [ ] Key pairs remain distinguishable under colour-blindness simulation
- [ ] Palette proportions are specified

## Typography
- [ ] Arabic and Latin typefaces are paired and optically matched
- [ ] Licences cover the client's intended use and are recorded
- [ ] Hierarchy defined for both scripts
- [ ] Fallback system fonts named

## System and applications
- [ ] Graphic elements, iconography and imagery direction defined
- [ ] At least five real applications shown
- [ ] Misuse examples included

## Guidelines document
- [ ] Follows the agreed outline and level
- [ ] No spelling errors in either language
- [ ] Colour values in the document match the swatches and files
