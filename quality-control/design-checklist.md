# Design checklist

Use for every designed piece: social, print, profile, presentation, digital.

## Brief
- [ ] Meets the objective and contains the agreed message and call to action
- [ ] Correct format, size and language(s)
- [ ] All mandatory elements present (logo, contact, legal line, licence numbers)

## Brand
- [ ] Correct logo version, clear space and minimum size respected
- [ ] Only brand colours and typefaces
- [ ] Imagery and graphic style match the guidelines
- [ ] Tone of voice is on-brand in each language

## Layout and typography
- [ ] Clear hierarchy; one focal point
- [ ] Consistent grid, margins and spacing
- [ ] No widows, orphans or bad line breaks
- [ ] Text is readable at the size it will be viewed
- [ ] Contrast meets WCAG AA for screen work

## Arabic
- [ ] Letters connected and correctly ordered in the exported file
- [ ] No letter-spacing, faux bold or faux italic
- [ ] Layout is right to left, including bullets, tables, charts and icons with direction
- [ ] Arabic and Latin optically matched in size
- [ ] One numeral system throughout, as recorded in `brand-context.md`
- [ ] Arabic punctuation correct; proofread by a native reader

## Content
- [ ] Zero spelling or grammar errors
- [ ] Names, numbers, dates, prices, phone numbers and URLs verified against the source
- [ ] No placeholder text or sample images
- [ ] Image and font licences in place

## Technical — screen
- [ ] sRGB, exact pixel dimensions, key content inside safe areas
- [ ] File size reasonable for its use

## Technical — print
- [ ] CMYK (plus named spots), images 300 dpi at final size
- [ ] Bleed and crop marks present; nothing important in the safe margin
- [ ] Body text 100K; fonts embedded or outlined
- [ ] Page count and imposition correct for the binding
- [ ] Finishes and die lines on separate spot layers

## Technical — presentations
- [ ] Master layouts used; no manual overrides
- [ ] Fonts packaged or available on the presenting machine
- [ ] Opens correctly on a second machine; PDF export included
