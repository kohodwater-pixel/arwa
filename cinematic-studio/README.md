# Cinematic Studio

Windows desktop application for cinematic AI video: describe a film in Arabic or English, get directing
decisions and an editable storyboard, generate each scene on your own ComfyUI server with Wan 2.2, then
edit, add sound and export an MP4 — with projects stored on your computer.

**Honest status:** the application, its local project system, director engine, storyboard, media library,
timeline, export and cost rules are built and tested. The ComfyUI and RunPod connections are built from the
official API definitions and tested against protocol doubles; **no video has been generated by a real model
through this app yet.** See `DEVELOPMENT_PLAN.md`.

## Build and run

Requirements: Rust (stable), Node.js 22, FFmpeg. On Windows also: WebView2 (part of Windows 11) and the
Visual Studio C++ build tools.

```
npm ci
npm run tauri dev          # run the desktop app in development
npm run tauri build        # build the Windows installer (target/release/bundle/nsis/)
```

For the installer, put `ffmpeg.exe` and `ffprobe.exe` in `src-tauri/resources/ffmpeg/` first
(the GitHub workflow does this from a pinned release).

## Tests

```
cargo test -p studio-core                                   # core, 18 tests
npm test                                                    # director engine, 7 tests
npm run build && cargo build -p studio-core --features dev-bridge && node tests/e2e.mjs   # interface end to end
pwsh tests/windows-install-test.ps1 -Installer <setup.exe>  # on Windows
```

## Layout

```
crates/core/      Rust core (all logic; no Tauri dependency)
src-tauri/        Tauri 2 shell, capabilities, installer configuration, icons
src/              React + TypeScript interface;  src/director/ is the Cinematic Director Engine
tests/            browser end-to-end test, ComfyUI test double, Windows install test
```

## First use

1. Install and open the app. Your library is created in `Documents/Cinematic Studio`.
2. Settings → ComfyUI server: enter the address (`https://…`, or `http://127.0.0.1:8188` for a local server)
   and the access token, then "Test connection".
3. Model Manager shows which Wan 2.2 files the server still needs.
4. New project → AI Video Creator → Storyboard → Generate.
5. Timeline / Audio Studio → Export Center.

A cloud GPU is optional and is never started without your approval: see `GPU_COST_POLICY.md`.
