# تقرير اختبار CREATIVE AGENCY OS

**آخر تحديث:** 2026-11-13 · **العميل التجريبي:** `clients/demo-sidra-coffee/` (شركة وهمية اختُلقت للاختبار فقط)

## الخلاصة

النظام يعمل من الموجز إلى حزمة التسليم. الوكلاء العشرة شُغّلوا كلٌّ على حدة وأنتجوا ملفات فعلية، وبوابة الجودة رفضت العمل مرات متتالية حتى صُحّح: سبع جولات مراجعة، سُجّلت تقاريرها كاملة. الحزمة النهائية للعميل التجريبي **محجوزة**، أي أنها اجتازت المراجعة الداخلية لكنها غير صالحة لعميل حقيقي قبل شروط لا يستطيع النظام استيفاءها وحده (أهمها تدقيق لغوي بشري ورأي محامي علامات).

## 1. الوكلاء

| الوكيل | النتيجة | ما أنتجه في الاختبار |
|---|---|---|
| market-researcher | يعمل | بحث السوق والمنافسين بمصادر؛ صرّح بما لم يستطع رؤيته بدل اختلاقه |
| brand-strategist | يعمل | الاستراتيجية والرسائل، ثم ملخص الاستراتيجية للعميل (v03) |
| naming-specialist | يعمل | فحص الاسم (اكتشف أن Sidra سلالة بنّ)، ثم بحث تعارض أولي وجد مخاطرة عالية |
| art-director | يعمل | اتجاهان إبداعيان، وثيقة التوجه، تعديلان عليها، مقارنة فعلية بهويات المنافسين، اعتماد التحريك |
| identity-designer | يعمل | الشعار (45 SVG، 135 PNG، 45 PDF)، النظام اللوني، دليل الهوية v04، متغيرات لونية في Figma |
| graphic-designer | يعمل | منشور إنستغرام عربي، تحريك شعار MP4، اختبار Canva |
| corporate-designer | يعمل | بروفايل ثنائي اللغة v04، وإخراج وثيقة الاستراتيجية PDF |
| presentation-designer | يعمل | عرض عربي RTL بقالب رئيسي (PPTX v03) |
| ui-ux-designer | يعمل | صفحة هبوط عربية RTL مكتفية بذاتها (v03)، مختبرة على أربعة مقاسات |
| quality-reviewer | يعمل | سبع جولات مراجعة؛ لا يملك صلاحية كتابة |

- حصر الأدوات مطبّق فعلاً: الاستراتيجي بلا Bash ولا أدوات تصميم، والمراجع بلا Write/Edit.
- المهارة المحمّلة مسبقاً ظهرت عند كل وكيل، واستدعاء المهارات الإضافية نجح (`brand-positioning`، `pptx`، `motion-multimedia`).
- كل وكيل ختم بصيغة التسليم الموحّدة وذكر ما لم يتحقق منه.

## 2. توزيع المهام

- **تسلسلي:** موجز ← بحث ← استراتيجية ← اتجاه إبداعي ← هوية.
- **متوازٍ:** حتى خمسة وكلاء معاً في جولات الإنتاج والتصحيح.
- **حل التعارض:** قرارات المدير الإبداعي مسجّلة في سجل القرارات بملف العميل (أكثر من ثلاثين قراراً مرقّماً).
- **درس مسجّل:** حين صدّر المدير الإبداعي وثيقة بنفسه بدل المختص، فشلت في المراجعة (عنوان مشوَّه واتجاه عربي خاطئ). أُضيف ذلك إلى القواعد.

## 3. Figma وCanva

| العملية | النتيجة |
|---|---|
| Figma: إنشاء ملف، كتابة متغيرات لونية وإطار بنص عربي | نجح، مع لقطة تحقق |
| Figma: كتابة وقراءة من داخل الوكلاء | نجح؛ تنزيل لقطة الشاشة فشل مرة (403) من داخل وكيل |
| Figma: خط IBM Plex Sans Arabic | غير متاح هناك (المتاح: Noto Sans Arabic وTajawal وCairo) |
| Canva: إنشاء منشور عربي، قراءته، تغيير مقاسه | نجح؛ الناتج عام خارج الهوية؛ تغيير المقاس ميزة تجريبية بقي منها استخدام واحد |
| Canva: Brand Kit | غير موجود في الحساب |
| خادما MCP الخاصان بالإضافتين | لا يتصلان عبر البروكسي؛ العمل تم عبر موصّلَي الجلسة |

## 5. جولات المراجعة

| الجولة | ما رُوجع | الحكم |
|---|---|---|
| 1 | البروفايل، الهوية، العرض، المنشور | رفض الأربعة (2 حرجة، 14 رئيسية) |
| 2 | النسخ المصحّحة + التحريك وصفحة الهبوط | البروفايل والعرض والمنشور: نجاح بملاحظات صغيرة؛ الباقي رفض |
| 3 | الهوية، التحريك، صفحة الهبوط | نجاح بملاحظات صغيرة |
| 4 | حزمة التسليم | رفض: الاستراتيجية غائبة والمصادر غير مجمّعة |
| 5 | الحزمة المعاد بناؤها + الاستراتيجية | رفض: ثلاث ملاحظات رئيسية في وثيقة الاستراتيجية وادعاء غير دقيق في README |
| 6 | الاستراتيجية v03، البروفايل v04، الحزمة | الاستراتيجية والبروفايل نجحا؛ الحزمة رُفضت لملاحظة رئيسية واحدة في دليل الهوية |
| 7 | دليل الهوية v05، الاستراتيجية v04، الحزمة، مع مسح لكل النصوص مقابل سجل القرارات | نجاح بملاحظات صغيرة كحزمة داخلية محجوزة؛ لا ملاحظات حرجة أو رئيسية؛ خمس ملاحظات صغيرة معلنة في README |

ما التقطته البوابة فعلاً: قناة تواصل مختلقة في منشور، عرض «عيّنة» غير موجود في الموجز، ادّعاء تحميص حسب الطلب للأفراد لم يؤكده العميل، اسم العلامة مكتوباً ناقصاً، خانة هاتف ناقص، وثائق تناقض القرارات، وحزمة ينقصها أحد بنود الموجز. ولم تجد في أي جولة إنجازاً أو رقماً أو عميلاً مختلقاً.

## 6. ما أُضيف للنظام بسبب الاختبار

- سكربتات: `site_capture.cjs` (التقاط مواقع المنافسين وقراءة خطوطها وألوانها)، `collect_html.py` (تجميع المصادر في مجلد مكتفٍ بذاته)، وخطوط IBM Plex Sans الثابتة.
- قواعد: ملاحظات Figma وCanva العملية، «القاعدة المتأخرة تُطبَّق على كل ما سبق»، تسمية `final` بعد اعتماد العميل فقط، الحزمة تشمل كل بنود الموجز، README بلغة العميل أولاً.
- بوابة جديدة: مراجعة حزمة التسليم نفسها مقابل الموجز، منفصلة عن مراجعة كل عمل.
- بيئة السحابة `creative-agency-os`: سكربت إعداد يثبّت الخطوط والمكتبات تلقائياً، والسماح بمواقع المنافسين للعميل التجريبي.

## 7. ما يبقى خارج قدرة النظام أو يحتاج قراراً

| البند | المطلوب |
|---|---|
| التدقيق اللغوي العربي | قارئ بشري قبل أي تسليم حقيقي |
| مشاهدة التحريك مُشغَّلاً | شخص يشغّل ملف MP4 على حاسوب وجوال |
| العلامات التجارية | النظام يُجري بحثاً أولياً فقط؛ الفحص القانوني عند محامٍ |
| رسم الشعارات | الشعار اللفظي حروف خط جاهز محوّلة لمسارات، لا رسم خاص |
| ألوان الطباعة | Pantone وCMYK المعايَرة تحتاج مرجعاً مرخّصاً وملف ICC من المطبعة |
| PowerPoint | ملفات PPTX لم تُفتح على PowerPoint حقيقي |
| مواقع محجوبة | كل نطاق يحتاجه مشروع يُضاف لإعدادات البيئة بموافقتك |
| سكربت إعداد البيئة | حُفظ في البيئة، ولم يُختبر بعد على جلسة جديدة |
| Canva | إنشاء Brand Kit لكل عميل؛ تغيير المقاس محدود في الخطة الحالية |
| Figma | خط العميل العربي قد لا يكون متاحاً هناك؛ الكتابة جُرّبت في المسودات فقط |
| ملفات تجريبية في حساباتك | ملف Figma واحد وتصميمان في Canva، يمكنك حذفها |
