# تقرير اختبار CREATIVE AGENCY OS

**التاريخ:** 2026-11-13 · **العميل التجريبي:** `clients/demo-sidra-coffee/` (شركة وهمية اختُلقت للاختبار فقط)

## الخلاصة

النظام يعمل من أوله إلى آخره: الوكلاء العشرة شُغّلوا كلٌّ على حدة، وأنتجوا ملفات فعلية، ومراجعة الجودة رفضت المخرجات الأربعة التي عُرضت عليها. الأعمال التجريبية **ليست جاهزة لعميل**، وهذا هو الحكم الصحيح لها.

## 2. توزيع المهام

- **تسلسلي:** موجز ← بحث ← استراتيجية ← اتجاه إبداعي ← هوية. كل مرحلة قرأت مخرجات سابقتها.
- **متوازٍ:** التسمية مع الاتجاه الإبداعي، ثم البروفايل والمنشور والعرض وصفحة الهبوط معاً.
- **الاعتمادات:** الموجز والاستراتيجية والاتجاه والهوية اعتمدها المدير الإبداعي بصفة «اعتماد اختباري» وسُجّلت في `brand-context.md`.
- **لم يُختبر:** خدمة الموشن (G)، وجولة التصحيح الثانية بعد المراجعة، ومجلد التسليم النهائي.

## 4. المخرجات والعربية

- PDF عربي وثنائي اللغة عبر `scripts/html2pdf.cjs`: يعمل، والملفات الثلاثة اجتازت `scripts/check_arabic_pdf.py` بالخطوط المقصودة دون خط بديل.
- PPTX عربي RTL قابل للتحرير: يعمل، وتحقّقنا منه عبر LibreOffice فقط، لا عبر PowerPoint.
- SVG للشعار بمسارات (بلا اعتماد على خطوط)، PNG، HTML: تعمل.
- DOCX وJPG وMP4: لم تُختبر.

## 5. مراجعة الجودة

الحكم: **رفض المخرجات الأربعة** (ملاحظتان حرجتان و14 رئيسية). التقرير الكامل في `clients/demo-sidra-coffee/08-final-delivery/_reviews/review_all-deliverables_2026-11-13_r1.md`.

- **حرجة:** تميّز الهوية عن المنافسين لم يُتحقق منه لأن هوياتهم الحقيقية لم تُشاهد؛ ومنشور السوشيال يذكر قناة طلب (الرسائل الخاصة) غير موجودة في الموجز.
- **رئيسية، أمثلة:** خانة رقم هاتف ناقص وعلامة «مسودة» في البروفايل، جملة عربية ملتبسة في «من نحن»، الشعار اللفظي حروف IBM Plex غير معاد رسمها، لا قيم Pantone ولا CMYK معايرة، الشعار الثنائي لا يُقرأ عند 16 بكسل.
- **ما صمد:** لم يُختلق أي إنجاز أو رقم أو عميل، والعربية متصلة وصحيحة الاتجاه في كل الملفات، والألوان المعتمدة مستخدمة بدقة.

## 6. ما يحتاج إصلاحاً أو قراراً

| البند | الحالة | المطلوب |
|---|---|---|
| التدقيق اللغوي العربي | لم يقم به قارئ بشري | مراجعة بشرية لكل نص عربي قبل أي تسليم حقيقي |
| مواقع المنافسين | محجوبة بسياسة شبكة البيئة | إضافة النطاقات المطلوبة لكل مشروع إلى إعدادات البيئة، أو تزويد الوكالة بلقطات |
| تثبيت الخطوط والمكتبات تلقائياً | غير مفعّل (حُجب إنشاء الخطّاف) | تشغيل `bash scripts/setup.sh` في بداية كل جلسة، أو الموافقة على خطّاف SessionStart |
| Canva Brand Kit | غير موجود | إنشاء Brand Kit لكل عميل لتفعيل الفحص الآلي |
| تغيير المقاس في Canva | ميزة تجريبية، بقي استخدام واحد | ترقية الخطة إن كان مطلوباً بكثرة |
| خط IBM Plex Sans Arabic في Figma | غير متاح | اختيار خط متاح في Figma للعملاء الذين ستُبنى هويتهم هناك، أو رفع الخط للحساب |

| اختبار PowerPoint | لم يتم | فتح ملفات PPTX على PowerPoint حقيقي قبل التسليم |
| خدمة الموشن وDOCX | لم تُختبرا | اختبار عند أول طلب فعلي |
| جولة التصحيح الثانية | لم تُشغَّل | إعادة الأعمال إلى أصحابها ثم مراجعة ثانية |
